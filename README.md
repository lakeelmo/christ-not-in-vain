# Christ Not In Vain

Interactive Minnesota Senate district map with sourced quotes, New Testament contrast, and a vision for prosperity for all.

**Live site:** https://lakeelmo.github.io/christ-not-in-vain/

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Single citizen project. Not affiliated with any party, campaign, or church.
